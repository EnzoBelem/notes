# Primeiros passos com Redis CLI

#DataBase 

## 1. Conectar ao Redis

```bash
redis-cli -h 127.0.0.1 -p 6379
```

## 2. Escrever e ler informações

```
SET nome "Enzo"
GET nome
```

Definir uma chave com expiração (em segundos) e consultar o tempo restante:

```
SET sessao "abc123" EX 60
TTL sessao
```

Outros comandos básicos:

```
EXISTS nome     # 1 se a chave existe, 0 se não
DEL nome        # remove a chave
KEYS *          # lista todas as chaves (evitar em produção, use SCAN)
```
