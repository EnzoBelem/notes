# Docker Hub

O **Docker Hub** é o maior registro de imagens de contêineres do mundo. Pense nele como o "GitHub das imagens Docker": um serviço baseado em nuvem onde desenvolvedores e organizações hospedam, compartilham e gerenciam seus repositórios de imagens.

---

## Como o Docker Hub funciona?

Ele atua como o ponto central no ecossistema Docker. O fluxo básico funciona através de uma arquitetura **Client-Server**:

1. **Storage (Armazenamento):** Ele armazena as camadas das imagens de forma otimizada.
    
2. **Pulling (Baixar):** Quando você executa `docker pull`, o Docker busca a imagem nos servidores do Hub.
    
3. **Pushing (Subir):** Quando você cria uma imagem localmente, você pode enviá-la para o Hub para que outros (ou seus servidores de produção) possam acessá-la.
    
4. **Repositórios:** Podem ser **Públicos** (gratuitos e visíveis para todos) ou **Privados** (restritos a você ou sua organização).
    

---

## Como subir suas próprias imagens (Passo a Passo)

Para subir uma imagem, você precisará de uma conta no [hub.docker.com](https://hub.docker.com/). Com a conta criada, siga estes passos no seu terminal:

### 1. Autenticação

Primeiro, conecte seu terminal à sua conta do Docker Hub:

Bash

```
docker login
```

Insira seu nome de usuário e senha (ou um Access Token, que é o mais recomendado por segurança).

### 2. Criar sua imagem (Build)

Se você já tem um `Dockerfile`, crie a imagem. **Importante:** a imagem deve seguir o padrão de nomeação `usuario/nome-da-imagem`.

Bash

```
docker build -t seu_usuario/minha-app:v1 .
```

### 3. Taggear a imagem (Opcional)

Se você já criou uma imagem com um nome comum, você pode criar uma "etiqueta" (tag) vinculando-a ao seu usuário:

Bash

```
docker tag imagem-local:latest seu_usuario/minha-app:v1
```

### 4. Enviar para o Hub (Push)

Agora, basta enviar a imagem para o registro:

Bash

```
docker push seu_usuario/minha-app:v1
```

---

## Dicas Rápidas

- **Tags:** Use tags para controlar versões (ex: `:v1`, `:v2`, `:latest`). Se você não especificar uma tag, o Docker usará automaticamente a `:latest`.
    
- **Official Images:** Sempre que possível, use imagens oficiais (como `node`, `python` ou `nginx`) como base no seu Dockerfile para garantir mais segurança.
    
- **Segurança:** Nunca coloque senhas ou chaves de API dentro das imagens que você subir para repositórios públicos.
