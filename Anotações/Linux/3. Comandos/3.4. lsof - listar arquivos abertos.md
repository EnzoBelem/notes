# lsof - listar arquivos abertos

#Linux 

O `lsof` (*list open files*) lista os arquivos abertos no sistema e os processos que os estão usando. No Linux **tudo é um arquivo**: arquivos comuns, diretórios, dispositivos, pipes e também sockets de rede. Por isso o `lsof` serve para investigar desde "quem está usando este arquivo?" até "qual processo está escutando esta porta?".

Cada linha da saída mostra, entre outras colunas, o comando associado (`COMMAND`), o `PID`, o usuário (`USER`) e o arquivo ou socket aberto (`NAME`).

## Uso básico

```bash
lsof              # lista todos os arquivos abertos no sistema
lsof | head       # só as primeiras linhas
lsof | wc -l      # quantos arquivos abertos existem
```

Sem `sudo`, o `lsof` só mostra o que o seu usuário pode ver. Com `sudo`, a lista fica bem maior.

## Filtrar por usuário

```bash
lsof -u usuario       # arquivos abertos por um usuário
lsof -u ^usuario      # todos, exceto os desse usuário
```

## Filtrar por processo

```bash
sudo lsof -c nginx    # por nome do comando (casa pelo início do nome)
lsof -p 1234          # por PID
```

## Conexões de rede

O `lsof` também lista os endereços de rede ligados a processos ativos:

```bash
lsof -i 4             # somente IPv4
lsof -i 6             # somente IPv6
lsof -i :8080         # quem está usando a porta 8080
lsof -i tcp:5432      # só TCP na porta 5432
lsof -iTCP -sTCP:LISTEN   # só sockets TCP em escuta
```

É útil para descobrir qual processo está ocupando uma porta quando aparece o erro "address already in use".

## Outros usos comuns

```bash
lsof /caminho/do/arquivo      # quem está com esse arquivo aberto
lsof +D /caminho/do/diretorio # arquivos abertos dentro de um diretório (recursivo, pode ser lento)
lsof +L1                      # arquivos apagados que ainda estão abertos (ocupam disco)
```

O último caso explica situações em que o espaço em disco não é liberado depois de apagar um arquivo grande, como um log: o arquivo some do diretório, mas o espaço só volta quando o processo que o mantém aberto é encerrado ou reiniciado.
