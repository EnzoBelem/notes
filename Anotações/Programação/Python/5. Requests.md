# Requests

#Python

A biblioteca `requests` é o cliente HTTP mais usado em Python. Instalação:

```bash
pip install requests
```

## Template de requisição simples

```python
import os

import requests


def teste_request():
    headers = {
        "Content-Type": "application/json",
        "Authorization": f"Bearer {os.environ['API_TOKEN']}",
    }
    url = "http://127.0.0.1:8000/v1/recurso/1/"
    try:
        response = requests.get(url, headers=headers, timeout=1)
        response.raise_for_status()
        print(response.json())
    except requests.RequestException as e:
        print(e)
```

- Nunca escreva tokens direto no código: leia de variável de ambiente (`API_TOKEN`) ou de um `.env` fora do Git.
- Sempre passe `timeout`. Sem ele, a requisição pode ficar travada indefinidamente.
- `raise_for_status()` levanta `requests.HTTPError` para respostas 4xx/5xx.
- `requests.RequestException` cobre todos os erros da biblioteca (conexão, timeout, HTTP), o que é mais preciso que `except Exception`.

## Outros métodos

```python
requests.post(url, json={"campo": "valor"}, headers=headers, timeout=5)  # envia JSON
requests.get(url, params={"page": 2}, timeout=5)                         # query string ?page=2
```

## Sessão

Para várias chamadas ao mesmo serviço, `requests.Session` reaproveita a conexão e mantém os headers:

```python
with requests.Session() as session:
    session.headers.update(headers)
    r = session.get(url, timeout=5)
```
