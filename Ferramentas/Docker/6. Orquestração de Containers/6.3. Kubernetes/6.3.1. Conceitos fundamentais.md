# Conceitos fundamentais

#Docker #Kubernetes

- **Control Plane**: Onde é gerenciado o controle dos processos dos Nodes. Basicamente a máquina em que o K8s foi configurado e que tem o papel de gerenciar as demais
- **Nodes**: Máquinas que são gerenciadas pelo Control Plane
- **Deployment**: A execução de uma imagem/projeto em um Pod
- **Pod**: Um ou mais containers que estão em um Node
- **Services**: Serviços que expõem os Pods ao mundo externo
- **kubectl**: Client de linha de comando para o Kubernetes

Para fins de aprendizado usaremos a ferramenta **Minikube**, que em resumo é um simulador de Kubernetes local. Sem ele precisaríamos de múltiplas máquinas para executar o Kubernetes.

Ambas as ferramentas podem ser facilmente instaladas na sua máquina seguindo os guias:
- https://minikube.sigs.k8s.io/docs/start/?arch=%2Flinux%2Fx86-64%2Fstable%2Fdebian+package
- https://kubernetes.io/docs/tasks/tools/install-kubectl-linux/

## Primeiros passos no minikube

```bash
minikube start
minikube status
minikube dashboard
minikube dashboard --url
```

O minikube usando Docker para rodar o Kubernetes pode ter problemas com imagens corrompidas. Nesse caso existem os seguintes comandos:

```bash
minikube delete
minikube delete --all --purge
```

## Deployment

